# WEB AFRICA — version de consultation

Tarifs de création : 75 000 FCFA (1 page), 115 000 FCFA (5 pages), 175 000 FCFA (8 pages), boutique sur commande, sur devis. Chaque formule de création de site : un nom de domaine .com standard offert la première année, sous réserve de disponibilité, hors domaines premium. Renouvellement à partir de la deuxième année à la charge du client, au tarif du fournisseur précisé au devis. Hébergement séparé. Domaine enregistré au nom du client.

Avec Node.js : lancer node build.mjs, puis node check.mjs, puis node server.mjs. Ouvrir http://127.0.0.1:4173/. Aucun paquet à installer.

Le générateur utilise upgrade.mjs et security.mjs. Les formulaires sont dans dist/brief-data.js. Les photos et leurs licences figurent sur la page Crédits.

Version non publiée, indexation désactivée. Avant publication : domaine final, identité légale, hébergeur, HTTPS et vérification des en-têtes. Les formulaires préparent un message local puis ouvrent WhatsApp ou la messagerie ; aucune collecte automatique côté serveur.
